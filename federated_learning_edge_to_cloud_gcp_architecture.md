# 🧠 架构核心升级点（基于你两个文档的关键加分点）

## 1️⃣ 不只是Edge + Cloud，而是“三层智能”
- Edge：实时决策（<100ms）
- Regional：合规 + 数据处理
- Global：学习与治理

---

## 2️⃣ MLOps闭环（面试最关键）

```
数据 → 特征 → 训练 → 评估 → 部署 → 监控 → 再训练
```

自动触发：
- 模型性能下降
- 数据漂移
- 新数据到达

---

## 3️⃣ Federated Learning（解决EU合规）

- EU：数据不出境
- 上传：模型更新 / embedding
- 全局：聚合学习

---

## 4️⃣ Feature Store（很多人会漏，强加分项）

作用：
- 跨工厂复用特征
- 保证训练/推理一致性

---

## 5️⃣ Active Learning（非常高级）

只标注：
- 最“不确定”的样本

👉 大幅降低标注成本

---

## 6️⃣ 模型漂移治理（面试重点）

检测：
- Data Drift（输入变了）
- Concept Drift（定义变了）

动作：
- 自动触发 retraining pipeline

---

# 🎯 一句话总结（面试用）

> 这是一个以 Vertex AI 为核心的端到端 MLOps 架构，通过 Edge AI 实现低延迟推理，通过区域隔离和联邦学习满足数据合规要求，并通过自动化 Pipeline 和模型监控实现持续优化与全球规模化部署。
